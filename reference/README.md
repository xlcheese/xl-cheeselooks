# Reference: xl_cheese-Mint-Y-Variable

The hand-made theme xl-Cheeselooks grew out of. Kept here as **starting material** for the templates, not as an installable theme. Only the text files are included; the original PNG and SVG assets are replaced by CSS or generated images in xl-Cheeselooks.

- `gtk-3.0/`, `gtk-4.0/`: based on Linux Mint's Mint-Y, with coral (`#FA8562` / `#F18065`) as the accent.
- `cinnamon/cinnamon.css`: based on Linux Mint's Mint-X Cinnamon theme (panel buttons, window list).
- `metacity-1/`: larger title bar button icons (the XML file was never written).
